피처 교란 지문 설계 (시뮬레이터 v2 안)

이상을 '곡선 모양'으로 직접 넣지 않고, 피처 하나의 실효값을 틀어지게 해서 GPC·균일도가 수식으로 따라 움직이게 했다. 피처마다 GPC 방향, 균일도 반응, 시간 모양이 서로 다르면 그래프만 보고 거꾸로 원인을 찾을 수 있다.

모델

실효 피처ᵢ(t) = 노브 설정값ᵢ + 숨은 교란 dᵢ(t)
GPC(t)    = 1.10 − 0.006·(T−255) + 0.08·max(0, 4.5−퍼지) − 4.0·max(0, 0.10−펄스)
            + 0.10·(압력−1.4) + 0.25·진폭·sin(2πt/40) + 0.0003·(유량−225) [과다면 0.0004] + 잡음
균일도(t)  = 0.90 + 0.002·|T−255| + 0.30·max(0, 4.5−퍼지) − 0.02·max(0, 퍼지−4.5)
            + 3.0·max(0, 0.10−펄스) + 2.0·max(0, 펄스−0.10) + 1.0·진폭 + 0.5·|압력−1.4|
            + 0.006·max(0, 225−유량) + 0.0012·max(0, 유량−225) + 잡음
진폭      = 압력 교란 × clamp((압력 설정 − 1.2)/0.2, 0, 1)      ← 압력 설정을 2칸 낮추면 진동이 멎는다
어떤 노브든 한 번 누르면 GPC 나 균일도 중 하나는 움직인다. 펄스·퍼지를 늘리는 쪽은 GPC 가 포화라 균일도만 움직인다

지문 지도 — 주입 후 300초, 잡음 없는 변화량

다섯 점이 서로 멀리 떨어져 있을수록 구분이 쉽다. 압력은 진동 진폭을 GPC 변화로 찍었다.

지문 표

대역: GPC 1.05–1.15 (기준 1.10, ±0.05), 균일도 0.50–1.30 (기준 0.90, +0.40). 잡음 GPC σ 0.006, 균일도 σ 0.02.

피처별 GPC · 균일도 (주입 −3분 ~ +7분)

조치 없음 맞는 노브 3회 (+120·150·180초) 틀린 노브 3회 (같은 시각) 정상 대역
